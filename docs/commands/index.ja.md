# コマンド

- [`/magi:clear`](clear/index.ja.md) - 非アクティブなデータをクリアします。
- [`/magi:cancel`](cancel/index.ja.md) - バックグラウンドで実行中のタスクをキャンセルします。
- [`/magi:merge`](merge/index.ja.md) - PRをレビューしてマージします。
- [`/magi:review`](review/index.ja.md) - PRをレビューします。
- [`/magi:triage`](triage/index.ja.md) - イシューをトリアージします。
- [`/magi:validate`](validate/index.ja.md) - 設定ファイルを検証します。
