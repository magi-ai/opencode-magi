# レビュー

[`review`](/src/prompts/review/review/task.md)は、レビュアーエージェントが初回レビューで使うプロンプトです。

このプロンプトでは、レビュアーエージェントにプルリクエストの差分だけのレビューと対応するイシューの要件を確認させ、判定させます。

## 実行タイミング

[CI分類](ci-classification.ja.md)後に、未レビューのレビューエージェントが実行します。

## カスタマイズ

このプロンプトをカスタマイズするには、`review.prompts.review`にプロンプトファイルのパスを指定します。

## プレースホルダー

| プレースホルダー | 説明                     |
| ---------------- | ------------------------ |
| `{pr}`           | プルリクエスト番号。     |
| `{owner}`        | リポジトリのオーナー名。 |
| `{repo}`         | リポジトリ名。           |
| `{worktreePath}` | ワークツリーのパス。     |
| `{baseSha}`      | ベースコミット。         |
| `{headSha}`      | ヘッドコミット。         |

## タグ

| タグ           | 説明                                           |
| -------------- | ---------------------------------------------- |
| `<review>`     | プルリクエストのレビュー文脈のJSON。           |
| `<ci_failure>` | スコープ内の失敗した必須チェックのJSON配列。   |
| `<persona>`    | 設定されている場合のレビュアーペルソナの本文。 |
