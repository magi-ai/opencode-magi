# 再レビュー

[`rereview`](/src/prompts/review/rereview/task.md)は、レビュアーエージェントが再レビューで使うプロンプトです。

このプロンプトでは、前回のレビューのHEADコミットから現在のHEADコミットの差分だけのレビューと未解決コメントが新しい差分とレビュースレッドの会話で修正されたかを確認し、修正済みスレッドの解決、未解決スレッドへの返信、または別の新しいレビューコメントを投稿させます。

## 実行タイミング

[CI分類](ci-classification.ja.md)後に、古いレビューを持つレビューエージェントが実行します。

## カスタマイズ

このプロンプトをカスタマイズするには、`review.prompts.rereview`にプロンプトファイルのパスを指定します。

## プレースホルダー

| プレースホルダー    | 説明                     |
| ------------------- | ------------------------ |
| `{pr}`              | プルリクエスト番号。     |
| `{owner}`           | リポジトリのオーナー名。 |
| `{repo}`            | リポジトリ名。           |
| `{worktreePath}`    | ワークツリーのパス。     |
| `{baseSha}`         | ベースコミット。         |
| `{previousHeadSha}` | 前回レビューのコミット。 |
| `{headSha}`         | 現在のヘッドコミット。   |

## タグ

| タグ                   | 説明                                           |
| ---------------------- | ---------------------------------------------- |
| `<review>`             | プルリクエストのレビュー文脈のJSON。           |
| `<previous_review>`    | 前回レビューのメタデータと本文のJSON。         |
| `<unresolved_threads>` | 未解決レビュースレッドのJSON配列。             |
| `<ci_failure>`         | スコープ内の失敗した必須チェックのJSON配列。   |
| `<persona>`            | 設定されている場合のレビュアーペルソナの本文。 |
