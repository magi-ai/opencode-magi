# 指摘検証

[`finding-validation`](/src/prompts/review/finding-validation/task.md)は、レビュアーエージェントが変更リクエストと判定した場合に、そのレビューコメントが妥当かどうかを検証するプロンプトです。

レビューコメントを投稿したレビュアーエージェントを賛成の1票としてカウントし多数決を行い、可決したレビューコメントを投稿します。レビューコメントがすべて否決した場合は、変更する箇所が無いと判断し、変更リクエストを承認に判定を変更します。

## 実行タイミング

レビューまたは再レビュー後に、変更リクエストと判定したレビュアーエージェントが1名でもいる場合に実行します。

## カスタマイズ

このプロンプトをカスタマイズするには、`review.prompts.findingValidation`にプロンプトファイルのパスを指定します。

## プレースホルダー

| プレースホルダー | 説明                     |
| ---------------- | ------------------------ |
| `{pr}`           | プルリクエスト番号。     |
| `{owner}`        | リポジトリのオーナー名。 |
| `{repo}`         | リポジトリ名。           |

## タグ

| タグ         | 説明                                                     |
| ------------ | -------------------------------------------------------- |
| `<findings>` | そのレビュアーが検証する他のレビュアーの指摘のJSON配列。 |
