# CI分類

[`ci-classification`](/src/prompts/review/ci-classification/task.md)は、レビュアーエージェントがレビュー結果を出す前に、失敗した必須CIチェックを分類するプロンプトです。

このプロンプトでは、各レビュアーエージェントに、失敗した各チェックがプルリクエストの変更によって起きたものか、不安定な実行、外部要因、インフラ要因の可能性が高いものかを判定させます。チェックごとにレビュアーの分類を多数決します。

スコープ内と判定された場合は、レビュアーエージェントのレビューのプロンプトに含まれます。スコープ外と判定された場合は、`review.checks.retryFailedJobs`で指定された回数まで再実行します。指定された回数を超えた場合は、後続のフェーズへ進み、実行結果で報告します。

## 実行タイミング

レビュアーエージェントがレビューする前に、必須チェックの結果を取得し、少なくとも1つの必須チェックが失敗している場合に実行します。

`review.checks.exclude`に一致するチェックは、分類前に無視されます。任意チェックはレビューをブロックせず、分類もされません。

## カスタマイズ

このプロンプトをカスタマイズするには、`review.prompts.ciClassification`にプロンプトのファイルのパスを指定します。

## プレースホルダー

| プレースホルダー | 説明                     |
| ---------------- | ------------------------ |
| `{pr}`           | プルリクエスト番号。     |
| `{owner}`        | リポジトリのオーナー名。 |
| `{repo}`         | リポジトリ名。           |
| `{worktreePath}` | ワークツリーのパス。     |
| `{baseSha}`      | ベースコミット。         |
| `{headSha}`      | ヘッドコミット。         |

## タグ

| タグ              | 説明                             |
| ----------------- | -------------------------------- |
| `<failed_checks>` | 失敗した必須チェックのJSON配列。 |
