# `magi:review`

PRのレビューを実行し、レビュー結果を投稿するコマンドです。

## 使い方

OpenCodeで次のコマンドを実行します。

```txt
/magi:review 123
/magi:review 123 124
/magi:review 123 --dry-run
```

## 引数

| 引数  | 必須 | 説明                                                                       |
| ----- | ---- | -------------------------------------------------------------------------- |
| `prs` | はい | レビューするPR番号またはPR URL。空白またはカンマ区切りで複数指定できます。 |

## オプション

| オプション                           | 説明                                       |
| ------------------------------------ | ------------------------------------------ |
| `--dry-run`                          | レビュー結果を投稿せずに実行します。       |
| `--retry-api-attempts <count>`       | APIリトライ回数を上書きします。            |
| `--language <language>`              | 実行時の出力言語を上書きします。           |
| `--merge` / `--no-merge`             | レビュー後の自動マージ設定を上書きします。 |
| `--close` / `--no-close`             | クローズ自動化の設定を上書きします。       |
| `--retry-failed-jobs <count>`        | 失敗したジョブの再実行回数を上書きします。 |
| `--concurrency-reviewers <count>`    | レビュアーの並列数を上書きします。         |
| `--concurrency-runs <count>`         | PR単位の並列実行数を上書きします。         |
| `--wait-checks` / `--no-wait-checks` | チェック完了を待つかどうかを上書きします。 |

## フロー

1. 設定を検証する。検証に失敗した場合は、コマンドを終了する。
2. PRを検証する。いずれかの条件に合致した場合は、12に進む。

- PRがクローズまたはマージ済みである。
- PRがドラフトである。
- PRが設定の`review.safety`の条件に合致しない。
- PRの作成者がレビューに使用するアカウントである。

3. PRの既存のレビューを確認する。レビュー後に新しい変更や返信がない場合は、そのレビュアーのレビューを省略して既存の判定を使用する。すべてのレビュアーが省略された場合は、5から8と10を省略する。
4. PRのチェックを確認する。
5. PRのチェックの失敗がPRの変更に起因するかをレビュアーが判定する。PRの変更に起因しないチェックの場合は、再実行する。
6. 省略対象以外のレビュアーがPRをレビューまたは再レビューする。レビュアーは、承認、変更リクエスト、クローズのいずれかの判定を行う。
7. 変更リクエストと判定したレビュアーの指摘をレビュアー間で検証し、過半数が賛成した指摘を採用する。採用された指摘がない場合は、そのレビュアーの判定を承認とみなす。
8. 設定の`review.merge.approvalPolicy`が`"unanimous"`、且つクローズと判定したレビュアーが少数派の場合は、そのレビュアーに承認または変更リクエストのいずれかを再判定させ、変更リクエストと判定した場合は、7と同様に指摘を検証する。
9. レビュアーの判定を集約し、コマンドの判定を決定する。
10. PRにレビューを投稿する。
11. PRをマージまたはクローズする。それぞれ、次のいずれかの条件に合致する場合は実行しない。

- マージ
  - コマンドの判定が承認ではない。
  - 設定の`review.automation.merge`の条件に合致しない。
  - PRが競合している。
  - PRのチェックが失敗または保留中である。
- クローズ
  - コマンドの判定がクローズではない。
  - 設定の`review.automation.close`の条件に合致しない。

12. 実行結果をレポートとして返す。
