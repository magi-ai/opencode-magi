# `magi:cancel`

Cancels tasks running in the background. When no pull request or issue number is specified, it cancels all background runs in progress.

## Usage

Run the following command in OpenCode.

```txt
/magi:cancel
/magi:cancel 123
/magi:cancel 123 124
```
