# `magi:cancel`

バックグラウンドで実行中のタスクをキャンセルするコマンドです。PRまたはイシューの番号を指定しない場合は、実行中のすべてのバックグラウンドの実行をキャンセルします。

## 使い方

OpenCodeで次のコマンドを実行します。

```txt
/magi:cancel
/magi:cancel 123
/magi:cancel 123 124
```

## 引数

| 引数      | 必須   | 説明                                                                                                                               |
| --------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `numbers` | いいえ | キャンセルするPRまたはイシューの番号。複数指定できます。指定しない場合は、実行中のすべてのバックグラウンド実行をキャンセルします。 |
