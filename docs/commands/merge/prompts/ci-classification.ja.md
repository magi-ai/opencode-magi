# CI分類

[`ci-classification`](/src/prompts/merge/ci-classification/task.md)は、エディターエージェントが変更した後に、失敗した必須CIチェックを分類するプロンプトです。

このプロンプトでは、各レビュアーエージェントに、失敗した各チェックがプルリクエストの変更またはエディターエージェントの変更によって起きたものか、不安定な実行、外部要因、インフラ要因の可能性が高いものかを判定させます。チェックごとにレビュアーの分類を多数決します。

エディターエージェントの変更後に発生した失敗は、無関係だと判断できる強い根拠がない限りスコープ内として扱います。

## 実行タイミング

エディターエージェントが変更した後に、必須CIチェックの結果を取得し、少なくとも1つの必須チェックが失敗している場合に実行します。

## カスタマイズ

このプロンプトをカスタマイズするには、`merge.prompts.ciClassification`にプロンプトファイルのパスを指定します。

## プレースホルダー

| プレースホルダー | 説明                     |
| ---------------- | ------------------------ |
| `{pr}`           | プルリクエスト番号。     |
| `{owner}`        | リポジトリのオーナー名。 |
| `{repo}`         | リポジトリ名。           |
| `{worktreePath}` | ワークツリーのパス。     |
| `{baseSha}`      | ベースコミット。         |
| `{headSha}`      | ヘッドコミット。         |

## タグ

| タグ              | 説明                             |
| ----------------- | -------------------------------- |
| `<failed_checks>` | 失敗した必須チェックのJSON配列。 |
