# 編集

[`edit`](/src/prompts/merge/edit/task.md)は、エディターエージェントに未解決のレビュースレッドを処理させるプロンプトです。

このプロンプトでは、エディターエージェントにプルリクエスト作成者として振る舞わせます。未解決スレッドごとに、修正する、要求に同意しない、または具体的な質問を返すことができます。

## 実行タイミング

[review](/docs/commands/review/index.ja.md)または[rereview](/docs/commands/review/index.ja.md)後に、未解決レビュースレッドがある場合のみ実行します。

## カスタマイズ

このプロンプトをカスタマイズするには、`merge.prompts.edit`にプロンプトファイルのパスを指定します。

## プレースホルダー

| プレースホルダー | 説明                     |
| ---------------- | ------------------------ |
| `{pr}`           | プルリクエスト番号。     |
| `{owner}`        | リポジトリのオーナー名。 |
| `{repo}`         | リポジトリ名。           |
| `{worktreePath}` | ワークツリーのパス。     |

## タグ

| タグ                   | 説明                               |
| ---------------------- | ---------------------------------- |
| `<unresolved_threads>` | 未解決レビュースレッドのJSON配列。 |
